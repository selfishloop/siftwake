# OFF1 UTF-8 doğrulama hızlandırması

## Dar değişiklik

OFF1 title/text/key ve typed metadata string doğrulaması64+ byte girdide
pinned `simdutf8=0.1.5` safe `basic::from_utf8` kullanır. Kısa string'ler
standart Rust yolu kullanır. SIMD invalid sonucu verdiğinde standart kontrol
yeniden çalışır; mevcut detailed corrupt error metni korunur. Unsafe API veya
doğrulamayı atlayan yol eklenmez. Aynı UTF-8/surrogate/overlong kuralları,
CRC/bounds/typed metadata grammar/key/version ve belge limitleri korunur.
Tampon/replay algoritması önceki IEEE sürümündeki haline geri döndü.

Bu genel byte/string doğrulama kütüphanesi daha önce optional rkyv bağımlılık
ağacında aynı sürümle vardı; şimdi küçük bir direct dependency'dir. Yeni DB/
arama motoru, feature veya source/WAL/index/cache biçimi yok. Native ortak
codec yoluna uygulanır; legacy JSON parser ve opt-in API kararı değişmez.
CPU dispatch/fallback kütüphanenin safe API'sine bırakılır; farklı CPU veya
zorlanmış software fallback performansı bu makinede ölçülmez.

## Tampon denemeleri

[Frame-plan](FRAME-PLAN-10K-20261013.md) iki prototipi reddedildi. Dinamik
reuse tepe working set'i~8 MiB artırdı. Header-plan RAM artışını giderdi ve
ilk aramayı hızlandırdı, fakat üçer warm process'in tüm p95 eşleşmeleri
yavaşladı. İki değişiklik de runtime'dan çıkarıldı; bu belge onların kazancını
UTF-8 kazancı gibi aktarmaz. Yeni bounded multi-frame testi ve read-only
proses bellek gözlem aracı korundu.

## Doğrulama ve açık işler

Final default/all-features `cargo test --all-targets`, `cargo fmt --check`
ve default/all-features `cargo clippy --all-targets -- -D warnings` geçti.
Source/index/cache cuts, single-byte corruption, process kill, native codec
ve0.1 fixture compatibility testleri dahil. Loglar
`benchmarks/utf8-{tests-default,tests-all-features,fmt,clippy,clippy-all-features}.log`.

UTF-8 differential test standart Rust ile32 hizalama,ASCII/Türkçe/Çince/
emoji/U+10FFFF/NUL,her byte cut ve çok sayıda tek-byte corruption ayrıca
0..299 byte random byte array için aynı validity/string/detailed error'ı
kontrol eder. Bunlar bounded unit bytes, yeni benchmark belge corpus'u değil.
Yeni multi-frame testi büyük→küçük→büyüyen→boş native replay'ı kapsar.
